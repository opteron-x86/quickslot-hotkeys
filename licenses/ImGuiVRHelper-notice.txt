Quickslot compiles the public API stub and header-only Client SDK into its DLL.
These upstream files are unchanged in third_party/imgui-vr-helper. The helper
plugin itself is a separate VR-only requirement and is not bundled.

The matching Quickslot source release includes these files, their licenses,
the integration source, pinned build inputs and BUILDING.md instructions for
rebuilding/relinking Quickslot with a modified API or SDK. Modifying these
library portions and reverse engineering to debug such modifications is
permitted under the LGPL. Preserve the upstream notices and applicable terms.
