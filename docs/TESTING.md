# Gameplay checks

Run these in a loaded game. Record the package version, Skyrim/SKSE version and controller or headset used.

| Area | Check |
| --- | --- |
| Updating | Groups, shortcuts, settings and presets survive installation and save/load. |
| Group lifecycle | Rename, bind and populate a group; enable auto-sort and change its behavior. Remove it and add another repeatedly. Each new group should be empty with a fresh name, default behavior and the lowest unused 1–8 key (1, 3 → 2), skipping the editor key. Check controller/VR defaults, unchanged bindings on other groups, Undo restoring all removed state, and save/load. Clear group should retain its name, bindings and settings. |
| Hold to browse | Tap equips the remembered entry. Hold, browse and release selects another. Cancel restores gameplay controls. |
| Tap to cycle | Returning from another group recalls the saved choice; subsequent taps advance. Check wrapping, rapid taps and unavailable entries. |
| Keyboard | Left/Right browses; Ctrl + Left/Right reorders. Both wrap and retain the highlighted entry. Ctrl belongs to the selector while browsing. |
| Optional shortcuts | Under Controls → Keyboard, disable all editing shortcuts and check that Ctrl/Shift/Alt group chords, Ctrl-arrows, Backspace and Delete reach other mods without triggering Quickslot actions. Plain arrows/wheel browsing and Escape/right-click cancellation should still work. Re-enable actions individually, including right/left capture in gameplay and Inventory/Magic and moving with capture disabled. Verify save/load, Undo and the separate menu-capture switch. |
| Action remapping | Disable Alt removal or remap it, enable unused-modifier group selection, and browse/cycle while holding Alt-to-walk. Remap capture/move/reorder and selected-item keys; check swaps, invalid/duplicate bindings, menu capture, Undo and preset import. Use X as a controller modifier, rebind unequip to Y, and check group-first/modifier-first press/release order, cancellation chords, menus and focus loss. Confirm old settings and VR defaults retain their behavior and HUD hints show the current cancel binding. |
| Consumables | Tap uses one dose. Browsing readies a dose. Check animation timing, poison confirmation, smart-potion ranking and restocking. |
| Smart Potion compatibility | Test vanilla, Apothecary and CACO separately. With health/magicka/stamina missing, check lowest/highest/best-fit restoration, exclusions, depletion and restocking. Check regeneration separately and ensure attribute-fortification potions never substitute for restoration. For CACO, test each configured duration and player conditions: the estimate must count only the active variant. Captured plugin-record tests pass through the classifier; actual Skyrim condition evaluation and drinking still require gameplay confirmation. |
| Powers and shouts | Check selection, activation, charge, cooldown and used-power dimming. |
| Hand selection while browsing | Enable mouse or bumper hand presets; choose each hand for a one-handed weapon, spell and smart weapon. Move an exact weapon between hands without taking another copy. Check shields/torches, two-handed items and incompatible consumable/voice/combination entries. Releasing the group key after a hand action must never equip or use again. Verify menu/focus cancellation, settings migration, custom bindings, Undo and unchanged saved defaults. |
| Equipment | Check left/right hands, shields, torches, two-handed weapons, spells and empty-hand actions. Highlights reflect the complete equipped entry. |
| Smart combinations | Check Best Sword + Best Mace, Best Axe + Best Shield, fixed + smart, spell + smart and two identical rules. Verify separate copies, tempering, missing items and restocking. |
| Item identity | Drop, retrieve, sell, buy, store and restock items. Weapons/shields follow their captured copies; torches follow stock of their saved type. |
| Favorites groups | Link each category and favorite/unfavorite inventory items, spells and shouts. Test more than 16 matches, identical/enchanted weapon copies, default hands, zero stock/restocking, exclusions/reset, manual restoration, hidden manual shared shortcuts, Undo, save/load and cross-character presets. Add/remove a favorite while a group selection or equip is pending; it must cancel rather than retarget. Check ambiguous weapon-stack guidance, controller/VR scrolling and long lists at small resolutions. |
| Shared shortcuts | Edit a shortcut used by several groups. Check all linked groups, Undo, save/load and preset import/export. |
| Menus | Inventory, Tween, QuickLoot and message boxes receive their controls. Opening a menu cancels pending Quickslot actions. QuickLoot leaves normal HUD visibility active. |
| QuickLoot opt-ins | Test keyboard-only, controller-only, both and neither. Open/close QuickLoot while holding a group and after releasing a queued equip or use; switch devices and check the original policy remains in force. Verify captured wheel/stick/D-pad navigation never reaches both interfaces, blocked releases cannot equip later, and Inventory/Tween/text entry/focus loss still cancel. Check the installed QuickLoot variant, settings migration and Undo. |
| Controller | Check modifier chords, D-pad navigation, right-stick pointer, drag, text entry, reconnect and focus changes. |
| Weapon status | Poison one of two identical weapons and confirm only that copy shows the green droplet, including smart selections and combinations. Apply/spend poison, fire arrows/bolts, switch ammunition, transfer/drop stock and save/load. Check zero and incompatible ammo, all selector/equipment layouts, text-only mode, display switches and small scales. |
| Equipment display | Right hand first; two-handed items occupy one entry. Check quantity badges, shout timers, spent-power dimming and text-only layouts. |
| Appearance | Check every style, text position, scale and spacing. Spacing changes gaps while icon size stays fixed. Test 720p, 1080p, ultrawide and 4K. |
| Position | Drag each widget, adjust X/Y, snap edges/centers and use Shift for free placement. Check screen edges and independent positions. |
| Visibility | Check show/dim/hide, combat, drawn weapons, browsing and independent equipment visibility. |
| VR | Check helper opening, pointer input, hand bindings, grip chords, headset placement and focus changes. |
| Integrations | Check the menu API with the launcher and RTSS on Windows. |
| IME overlays | Open the editor and trigger a cursor-only language bar, type, select candidates and close the editor. Test a SimpleIME version that still pushes its language-bar menu, since its newer workaround masks the original failure. Inventory/Map/Console, a modal overlay, and loss of window focus must still close the editor and log why. Physical in-game verification is pending. |
| IME text-input ownership | Use SimpleIME's released engine-input routing declaration for end-to-end Chinese typing; disable it separately for counter-ownership testing, since its automatic GFx route does not deliver committed Chinese to Quickslot. Open/close the editor at least six times and confirm the acquisition log appears after the editor menu opens. In a debug session, clear `ControlMap::GetRuntimeData().textEntryCount` while the editor is open: typing must recover without reopening, with one recovery warning per session. Also clear it immediately before closing; the count must not become negative. Check normal keyboard input without an IME, another owner's balanced claim/release, cancellation before menu show, focus loss, game load/reset and unexpected editor-menu removal. Automated ownership checks run in the Linux and Windows interaction probes. |

The SimpleIME author [verified the #3 ownership fix](https://github.com/opteron-x86/quickslot-hotkeys/pull/4#issuecomment-6380918875) with nine cycles without its Quickslot declaration and three end-to-end Chinese-input cycles with the declaration. The ordering fix prevented the counter reset in-game; the recovery path is covered by the automated interaction probes.

For failures, include `Quickslot.log`, reproduction steps and relevant equipment/input mods. For crashes, include the crash log. Report automated test results and in-game observations separately.
