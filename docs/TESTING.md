# Gameplay checks

Run these in a loaded game. Record the package version, Skyrim/SKSE version and controller or headset used.

| Area | Check |
| --- | --- |
| Updating | Groups, shortcuts, settings and presets survive installation and save/load. |
| Load repair | Remove a key from `Quickslot.settings.json` and set another to an invalid value; verify the remaining settings load, the on-screen message appears after loading a save, and `Quickslot.settings.rejected.json` holds the original. Load a save written by a build with a different group schema; verify the message, save again without creating groups, and confirm the original build still reads its groups. |
| Group lifecycle | Rename, bind and populate a group; enable auto-sort and change its behavior. Remove it and add another repeatedly. Each new group should be empty with a fresh name, default behavior and the lowest unused 1–8 key (1, 3 → 2), skipping the editor key. Check controller/VR defaults, unchanged bindings on other groups, Undo restoring all removed state, and save/load. Clear group should retain its name, bindings and settings. |
| Hold to browse | Tap equips the remembered entry. Hold, browse and release selects another. Cancel restores gameplay controls. |
| Tap to cycle | Returning from another group recalls the saved choice; subsequent taps advance. Check wrapping, rapid taps and unavailable entries. |
| Cycling with both hands | Enable Keep the other hand equipped while cycling. Hold a captured sword in the right hand and cycle a left-hand group containing that copy and a dagger; the sword stays equipped as the dagger is selected. Repeat with the hands reversed, two identical base-form copies, differently tempered or enchanted copies, Favorites-linked groups and Best Sword. A smart rule should choose the strongest eligible copy. Check recall, wrapping, rapid taps, Skip unavailable items, a group containing only the occupied copy, save/load and Undo. Disable the option and verify cycling transfers the selected copy. Enable it again, browse and choose a hand explicitly to transfer. Check normal spell, two-handed and combination equipment. |
| Combined tap/hold mode | Select Tap to cycle / hold to browse. Check first-tap recall, repeated taps, wraparound and Skip unavailable items. Hold to open the selector at the current item, browse in both directions and release. Test early mouse-wheel/bumpers, smart weapons, the opposite-hand option, keyboard, controller chords and VR. Cancel with Escape/B, modifier release, a menu or lost focus. Verify one action per gesture, responsive tap release, Undo, save/load and presets. |
| Dedicated consumable action | Bind Use selected consumable for keyboard and controller/VR. Set a group’s Consumables option to Use selected consumable action. Select a potion by cycling, then by browsing and releasing; use the dedicated binding and verify one dose. Check food, poisons, smart potions, depletion/restocking, another consumable group, mixed equipment, the equipment widget, save/load and complete presets. Hold the use button and verify a single activation. Test rapid presses during an animation or poison confirmation, cancellation, menus/QuickLoot, conflicting bindings, modifier-first configuration, Undo and restoring Tap to use. |
| Cycle confirm delay | Set a delay with each game-speed mode (full, slow motion, pause; with and without Skyrim Souls RE). Tap a cycle group several times: the selector shows each choice, the game slows or pauses, and one equip follows the last tap. Check tap-to-cycle / hold-to-browse groups, recall after switching groups, cancel by keyboard, mouse and controller, switching groups during the delay, opening a menu during the delay, and zero delay equipping on every tap. Change **Hold delay** and confirm tap and hold thresholds follow it; with no saved value, the INI `HoldMilliseconds` applies. |
| Keyboard | Left/Right browses; Ctrl + Left/Right reorders. Both wrap and retain the highlighted entry. Ctrl belongs to the selector while browsing. |
| Optional shortcuts | In Controls → Keyboard → Remap actions, set group editing modifiers to None and clear selected-item bindings. Check that their keys pass through, unused-modifier selection still follows its separate setting, and rebinding an action enables it. Verify conflict swaps, Undo, Reset keyboard actions, saved disabled actions and preset/save-load round trips. |
| Action remapping | Disable Alt removal or remap it, enable unused-modifier group selection, and browse/cycle while holding Alt-to-walk. Remap capture/move/reorder and selected-item keys; check swaps, invalid/duplicate bindings, menu capture, Undo and preset import. Use X as a controller modifier, rebind unequip to Y, and check group-first/modifier-first press/release order, cancellation chords, menus and focus loss. Confirm saved settings and VR defaults load correctly and HUD hints show the current cancel binding. |
| Consumables | Tap uses one dose. Browsing readies a dose. Check animation timing, poison confirmation, smart-potion ranking and restocking. |
| Powers and shouts | Check selection, activation, charge, cooldown and used-power dimming. |
| Hand selection while browsing | Enable mouse or bumper hand presets; choose each hand for a one-handed weapon, spell and smart weapon. Move a weapon between hands and verify its identity. Check shields/torches, two-handed items and incompatible consumable/voice/combination entries. Verify exactly one equip action across the hand selection and subsequent group-key release. Verify menu/focus cancellation, settings migration, custom bindings, Undo and unchanged saved defaults. |
| Equipment | Check left/right hands, shields, torches, two-handed weapons, spells and empty-hand actions. Highlights reflect the complete equipped entry. |
| Smart combinations | Check Best Sword + Best Mace, Best Axe + Best Shield, fixed + smart, spell + smart and two identical rules. Verify separate copies, tempering, missing items and restocking. |
| Item identity | Drop, retrieve, sell, buy, store and restock items. Weapons/shields follow their captured copies; torches follow stock of their saved type. |
| Favorites groups | Select Weapons and Shields/Torches together, then add Spells. Check alphabetical order, unique entries and default-hand rules. Select All Favorites, clear a category, clear every category, then restore Manual. Favorite/unfavorite inventory items, spells and shouts. Test more than 16 matches, identical/enchanted weapon copies, zero stock/restocking, exclusions/reset, hidden manual shared shortcuts, Undo, save/load, older single-category saves/presets and cross-character presets. Add/remove a favorite while a group selection or equip is pending; verify cancellation. Check controller/VR category selection and scrolling, ambiguous weapon-stack guidance and long lists at small resolutions. |
| Shared shortcuts | Edit a shortcut used by several groups. Check all linked groups, Undo, save/load and preset import/export. |
| Menus | Inventory, Tween, QuickLoot and message boxes receive their controls. Opening a menu cancels pending Quickslot actions. QuickLoot leaves normal HUD visibility active. |
| Console cursor | Open the console immediately after loading a save, then repeat after opening and closing the Quickslot editor. Move the mouse and select a world object; verify the pointer, console text entry and normal controls after closing. Repeat rapid open/close cycles and open the console while browsing a group. Verify Quickslot stays hidden and its hotkeys yield while the console is open. Then open Biggie Traits or another UIExtensions menu and check its navigation and return to gameplay. |
| Custom menus | Open UIExtensions menus in Proteus/AddItemMenu and Biggie Traits through their own spells or controls. Verify that each menu appears, accepts navigation and confirmation, and returns to gameplay on closing. Repeat with keyboard and controller, and with Skyrim Souls pausing and unpausing CustomMenu. Open a menu during a held Quickslot selection or pending action; verify cancellation and normal Quickslot controls after closing. Open a custom menu over Inventory/Magic and verify its controls, then close it and capture an item into a group. |
| QuickLoot opt-ins | Test keyboard-only, controller-only, both and neither. Open/close QuickLoot while holding a group and after releasing a queued equip or use; switch devices and verify that the active action follows the device policy it started with. Verify navigation reaches the interface selected by the device policy, opening a blocking menu cancels queued actions, and Inventory/Tween/text entry/focus loss cancel selection. Check the installed QuickLoot variant, settings migration and Undo. |
| Controller | Check modifier chords, D-pad navigation, right-stick pointer, drag, text entry, reconnect and focus changes. |
| Controller binding editor | Clear a group binding, choose its modifier, then its button. Repeat in the opposite order for groups, Open editor and Browsing actions. Temporarily select equal buttons or a duplicate chord, then correct the other field; check the previous binding stays active until completion. Check Cancel, Undo, reset, reopening, saved settings and VR bindings. |
| Weapon status | Poison one of two identical weapons and confirm only that copy shows the green droplet, including smart selections and combinations. Apply/spend poison, fire arrows/bolts, switch ammunition, transfer/drop stock and save/load. Check the count on the bow itself with weapons drawn and sheathed, including the equipped display, and verify ammo shortcuts highlight as equipped. Check zero and incompatible ammo, all selector/equipment layouts, text-only mode, display switches and small scales. Check droplet readability against light and dark scenery. |
| Equipment display | Right hand first; two-handed items occupy one entry. Check quantity labels, shout timers, spent-power dimming and text-only layouts. Enable Show equipped ammunition; equip arrows, switch to bolts, fire shots, exhaust the stack and unequip ammo. Verify names and counts, the empty state, all layouts and editor previews. Toggle Show bow ammunition independently and check Save/Load, Undo and appearance presets. |
| Appearance | Compare spacing 0, 32 and 128 in Groups, Selector and Equipment. Zero gives compact frames; higher values increase the gaps. Try all six equipment arrangements, the three layout presets, names, text positions and ammunition. Preview zoom stays steady while adjusting spacing; Fit preview shows the full layout. Check save/reload and Undo. Test 720p, 1080p, ultrawide and 4K. |
| I4 icons | Install I4 1.1.0+ and the icon packs under test. Compare a weapon and spell with custom I4 icons against their SkyUI inventory/magic entries. Check keyword and FormID assignments, Original colors, Theme/White tint, transparency, unavailable-item dimming and paired shortcuts. Browse a large Favorites group, change layouts, open editor previews and load another save. Check the dependency message with I4 disabled or an older version installed, and category artwork with a missing icon source or frame. Change a smart rule’s winning item and verify its icon; check both items in a smart combination, depleted smart potions, empty-hand actions and unarmed. Repeat with loose-file and archive icon packs, then check SE/AE and VR rendering. |
| PNGII icons | Install I4, PNGII with icon API v1, and a pack containing PNG and SVG item or spell icons. Enable **Appearance → Style → Use PNGII icons**. Compare mapped weapons and spells against their inventory/magic icons in the widget, browser, equipment display and editor preview. Check FormID, keyword and I4-label rules; Original colors; Theme/White tint; transparency; wide and tall artwork; smart selections; combinations; and the `armor_hands` label for empty-hand actions. Toggle the option several times and confirm artwork changes between PNGII and I4 while the editor and pointer stay responsive. Close and reopen the editor, then check inventory and magic menus. Check an unmatched item and a missing or invalid image for I4 fallback. Save/reload and load another save. Repeat with loose files and a loaded BSA. With PNGII absent or an older build installed, confirm I4 icons and normal startup. |
| Interface matching | With no settings file, launch under each supported interface mod and confirm the Automatic theme resolves to it (`Installed interface:` in `Quickslot.log`), including with an unrelated HUD patch overriding `hudmenu.swf`. Check an unsupported interface (Minimal palette with the installed UI font) and vanilla. Select each **Font** entry, **Installed UI font** and **Theme font**; verify HUD, selector, equipment and editor text, CJK fallback glyphs, and save/reload. Compare frame corners on cards, squares, list rows and diamonds for each atlas theme at small and large scales, and the editor's colors under each theme. |
| Editor navigation | Step through tabs with LB / RB and pages with LT / RT on Xbox and PlayStation layouts; confirm they stay inactive while a slider is being adjusted, a popup is open, a binding is being captured and in Position mode. Check item artwork in the inventory list, group list and shortcut rows with I4 and PNGII packs, unavailable entries, combinations and long lists. Delete a preset, cancel a deletion, and delete a preset that was removed on disk. Type punctuation on the on-screen keyboard. |
| Character settings | Enable **Keep settings with this character** on one character, change theme, bindings and group names, and save. Load a second character (shared settings), start a new game, then reload the first (its own settings). Confirm the shared settings file stays unchanged while the option is on, changes made without saving are absent after reload, turning the option off writes the current settings to the shared file, and an older build loads the save with shared settings. |
| Previous selection | Select entries in two groups, then use **Return to previous selection** repeatedly; equipment alternates between the two. Check combinations, two-handed weapons, spells, entries reordered or removed since selection, hidden groups, and a fresh load (message, equipment unchanged). Enable double tap: two quick taps of the current group return to the earlier selection, slower taps keep their normal action, and cycle groups, consumable groups and hand selections behave as before. Rebind the key against group, consumable, editor and selector keys. Call `Quickslot_TapGroup`, `Quickslot_SwapPrevious` and `Quickslot_GetGroupCount` from a test plugin in gameplay, in a menu, with the editor open and before loading. |
| Wheel selector | Select **Wheel** and browse groups of 1, 2, 5 and 16 items. Point with each controller stick setting, the VR stick or touchpad, and the mouse; confirm the hub marker, highlight and released selection agree, the camera holds still for the mouse and resumes after release, and a centered stick keeps the last choice. Check scrolling, previous / next, hand actions, unequip, reorder, cancel, slow motion and pause, unavailable entries, every tile shape and spacing 0–128, small resolutions, and the editor preview. |
| Motion and sound | With **Animate opening and fading** on, check the widget easing in after menus and loading, selector open/close on hold, release and cancel, the equip pulse on each tile shape, the dose pulse on consumables, and the shout cooldown shade against the seconds for short and long shouts. Confirm editor previews stay steady. Turn the option off and confirm instant changes. With **Interface sounds** on, check open, step and cancel sounds for keyboard, controller and the cycle confirm delay; confirm silence when off. Adjust **Equipped marker size** and **Custom equipped color** across tile shapes, selector styles and themes. |
| Position | Drag each widget, adjust X/Y, snap edges/centers and use Shift for free placement. Check screen edges and independent positions. |
| I4 startup | Test the current I4 build on a modern runtime and Fuzzles' port on Skyrim 1.5.97. Verify the logged provider version, API availability and item icons. Check startup with I4 disabled and with an older provider lacking ProcessEntry; dependency errors should appear in Skyrim's interface and identify the missing component. Repeat a failed launch with the corrected installation and confirm icon rendering. |
| Visibility | Check show/dim/hide, combat, drawn weapons, browsing and independent equipment visibility. |
| VR | Check helper opening, pointer input, hand bindings, grip chords, headset placement and focus changes. |
| Integrations | Check the menu API with the launcher and RTSS on Windows. |
| IME overlays | Open the editor, display a cursor-only language bar, type and select candidates. Verify the editor stays open during text entry. Open Inventory, Map, Console or a modal overlay, then test window focus loss. Verify editor closure and the recorded reason for each case. |
| IME text-input ownership | Enable SimpleIME's engine-input routing declaration and test Chinese text entry. Run a separate ownership check with that declaration disabled. Open and close the editor at least six times and verify balanced input ownership. In a debug session, clear `ControlMap::GetRuntimeData().textEntryCount` during editing and immediately before closing; verify continued typing and a counter value of zero or greater. Test ordinary keyboard input, shared ownership, cancellation during opening, focus loss, game load/reset and unexpected editor-menu removal. |

For failures, include `Quickslot.log`, reproduction steps and relevant equipment/input mods. For missing I4 icons, check the logged API availability, source files and capture failure stage; compare the same items in SkyUI's inventory and magic menus. For crashes, include the crash log. Report automated test results and in-game observations separately.
