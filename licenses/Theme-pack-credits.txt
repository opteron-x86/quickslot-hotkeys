Quickslot 0.17.0 — theme artwork and fonts

Theme artwork:
All 16 external theme packs in Quickslot/themes/ use original Quickslot-authored
SVG artwork and color palettes licensed with Quickslot. SHA-256 checksums for
all bundled SVG assets are recorded in themes/packs-manifest.json.

Interface compatibility and visual pairing:
Quickslot includes automatic interface detection and coordinated visual palettes
for the following Skyrim UI overhauls (no upstream SWFs, textures, or binaries
from these mods are distributed):
- Oathvein UI — Nithog (https://www.nexusmods.com/skyrimspecialedition/mods/160916)
- Norden UI — Nithog (https://www.nexusmods.com/skyrimspecialedition/mods/166086)
- Vel'dun UI — Nithog (https://www.nexusmods.com/skyrimspecialedition/mods/176230)
- NORDIC UI — outobugi (https://www.nexusmods.com/skyrimspecialedition/mods/49881)
- Edge UI — EugeneUI (https://www.nexusmods.com/skyrimspecialedition/mods/130983)
- Untarnished UI — Vorganger (https://www.nexusmods.com/skyrimspecialedition/mods/75188)
- Dear Diary Dark Mode — uranreactor (https://www.nexusmods.com/skyrimspecialedition/mods/60837)
- Amethyst UI (SkyHUD / Dear Diary Dark configuration)
- Horizons UI — rob18
- Immortal UI
- Outlander UI II

Original signature Quickslot themes:
- Crimson Filigree, Dwemer Aetherium, Sovngarde Astral, Imperial Parchment,
  and Daedric Oblivion are original Quickslot designs.
